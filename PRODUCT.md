# Product

## Register

product

## Users

Software engineers, architects, technical leads, and product-minded builders comparing practical software quality tradeoffs. They use the tool while reasoning about priorities, design pressure, and second-order effects in real systems.

## Product Purpose

Software Metrics is an interactive quality tradeoff explorer. It helps users see how raising one software quality attribute can support or damage others, so architectural and product conversations become more explicit.

## Brand Personality

Sharp, practical, analytical. The interface should feel like a dense professional instrument, not a marketing page or generic dashboard.

## Anti-references

Avoid SaaS hero-metric cliches, decorative dashboards, vague AI-generated cards, and academic formality that hides practical judgment behind fake precision.

## Design Principles

- Keep the tradeoff graph legible under pressure.
- Treat cost, complexity, and reliability as foundational context for every software decision.
- Prefer concise expert copy over explanation-heavy onboarding.
- Make opinionated assumptions visible instead of pretending the model is scientific.

## Accessibility & Inclusion

Use semantic controls, keyboard-accessible interactions, visible focus states, and color-independent labels for positive and negative effects.
